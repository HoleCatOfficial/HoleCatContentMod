# Constantine's Arsenal

DestroyerTest, Formally known as Constantine's Arsenal, is a mod centered around adding weapons to the game that Constantine can use in his playthroughs. The end goal of the mod is to have multiple similarly functioning weapons on the same tier, to allow Constantine, and other players, to not need to break their visual style to use the best fitting option.

---

## Content and Updates
This mod is a passion project, but is also being used as a Capstone project to fulfill a graduation requirement at my high school.
As such, I have an itinerary of content to add, and will be updating it semi-frequently.
